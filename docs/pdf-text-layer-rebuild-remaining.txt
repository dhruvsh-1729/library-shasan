== RUNBOOK (run from the library repo folder, with the Kingston SSD plugged in)

Every step is checkpointed per book under ocr_work/relayer and ocr_work/relayer_aligned:
finished books are skipped, a stopped book resumes where it stopped. --no-delete keeps
the old PDFs on UploadThing.

1) Published books (29): three parallel runs
   W=/media/dell/KINGSTON/ocr_work
   for k in 0 1 2; do nohup node --env-file=.env scripts/google/relayer_pdfs.mjs $W/relayer --shard=$k/3 --no-delete > $W/relayer/run3_$k.log 2>&1 & done

2) Aligned books (7; 453, 455 and 456 will fail the safety check on purpose, keep their PDF)
   A="$W/g144/books_deva.json+$W/g144/books_guj.json+$W/g144/books_old.json,$W/g144/custom_ids.json,$W/g144/work_deva/out,$W/g144/work_guj/out,$W/g144/work_453/out,$W/modern/out,$W/ld/out"
   nohup node --env-file=.env scripts/google/relayer_pdfs.mjs $W/relayer_aligned --aligned=$A --no-delete > $W/relayer_aligned3.log 2>&1 &

3) Progress:   bash $W/status_all.sh      Logs: grep -h "relayered\|FAILED" $W/relayer/run3_*.log $W/relayer_aligned3.log

4) Optional, only if you want the superseded PDFs removed (permanent on UploadThing;
   the originals stay on this SSD). Waits 15 min after each swap so no cached link breaks:
   node --env-file=.env scripts/google/relayer_pdfs.mjs $W/relayer --delete-only
   node --env-file=.env scripts/google/relayer_pdfs.mjs $W/relayer_aligned --aligned=$A --delete-only
